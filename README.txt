THE LIFE — EXPANDED INTERACTIVE BIOLOGY PORTAL
================================================

START
-----
1. Extract this ZIP file.
2. Open index.html in Chrome, Edge or Firefox.
3. The website works offline. Keep all folders together.

WHAT IS INCLUDED
----------------
• 60 self-contained HTML pages.
• Every HTML file contains its own CSS and JavaScript.
• No external stylesheet or JavaScript file is required.
• Original diagrams, images and videos are retained.
• 21 dedicated cell-organelle lesson pages.
• Expanded lessons on biomolecules, microbiology, evolution, ecology,
  cell transport, respiration, photosynthesis, genetics, plant physiology,
  plant reproduction, human nutrition, homeostasis, immunity and development.
• Study Hub with learning path, timeline, science skills, glossary and revision.
• Search, dark mode, text resizing, read-aloud, printing, quizzes, flashcards,
  lesson completion and personal notes.
• Progress and notes are stored only in the learner's browser.

UPLOAD TO GITHUB PAGES / NETLIFY
--------------------------------
Upload the entire extracted folder, with index.html at the root.
Paths contain spaces, so do not rename only one file or folder without updating links.

IMPORTANT
---------
For the best offline experience, use a modern browser.
Browser-saved notes and progress are device/browser-specific.
